# AutoStation 行为说明

AutoStation 牌子是“站点行为节点”，用于执行停站/开关门/发车，不负责调度寻路。

## 触发条件
- 仅在列车具备 `FTA_OPERATOR_CODE/FTA_LINE_CODE/FTA_ROUTE_CODE`（或 `FTA_ROUTE_ID`）tag 且 RouteStop 标记为 `STOP/TERMINATE` 时停站。
- 若 RouteStop 未填写 `dwellSeconds`，默认停站 20 秒；若填写 `<= 0` 则视为不停车。
- 未匹配到 RouteStop 或无 route tag 的列车视为 waypoint，直接通过。
- RouteStop 匹配顺序：先按站点 ID（同运营商 + 站点 code）匹配，失败后再用 waypoint nodeId 匹配。
- 兼容 `[train]` 与 `[cart]`：`[cart]` 只会触发 `MEMBER_ENTER`，因此仅处理车头触发一次，避免长编组重复停站。

## 牌子格式
```
[train] / [cart]
autostation
<Operator:S:Station:Track>
<门方向: N/E/S/W/NE/NW/SE/SW/BOTH/NONE>
```

说明：
- 第 3 行为站点节点 ID（4 段 `S` 格式）。
- 第 4 行为开门方向：N/E/S/W/NE/NW/SE/SW 为世界方向；BOTH 双侧开门；NONE 不开门。
- 第 4 行为空或无法识别时同样不开门，但视为漏写：建牌时提示建牌者，列车在此停站时写一条 WARN（点名节点与第 4 行原文，同一节点每次运行只写一次）。确实不开门的站台请显式写 NONE。

方向说明：
- N/E/S/W/NE/NW/SE/SW 是牌子文本写出的世界绝对方向，不是牌子方块朝向、轨道方向、列车行进方向或相对于列车的方向。
- 门侧判定只比较 `doorL` 与 `doorR` 附件目标在该世界方向上的投影；投影更大的那一侧更靠近牌子写出的世界方向。
- **逐节判定**：每节车只看自己的 `doorL`/`doorR` 附件，各自决定开哪一组。反着挂的车厢（联挂时整组掉头、存车里镜像放置的尾车）开另一组；`doorL` 与旧名 `doorL10` 混用的列车各节按自己的动画名播放。
- 某节车判不出（门附件没有位置信息、两侧投影重合）时，按最近一节已判出的车厢推：两节车模型的前向量夹角不超过 90° 开同一组，否则开另一组；前后一样近时取前面那节，读不到朝向按同向处理。
- 斜向站台可直接写 NE/NW/SE/SW，例如 SE 表示世界东南（X+、Z+），NW 表示世界西北（X-、Z-）。
- 若没有一节车能取得 `doorL` / `doorR` 的可靠世界位置、或两侧投影都无法区分，将不执行开门，避免误开对侧。
- 人工驾驶开门同样逐节判定：把驾驶员左（右）手边换算成世界方位后按上面的规则逐节选组；对侧门已开时取相反的世界方位。读不到驾驶员朝向、逐节也判不出时，才按整列的结果（再不行按驾驶室在车头还是车尾）全车开同一组。

## 开关门动画
- 标准动画：`doorL` / `doorR`（相对列车行进方向的左/右门）。
- 旧车兼容：`doorL10` / `doorR10` 会按时长切分为开门/关门两段；其他 legacy 动画会截取开门段并在关门时反放。
  - 对 `doorL10/doorR10`：默认取前 5 秒作为开门段，剩余部分作为关门段；若总时长不足 10 秒则按一半切分。
  - 其他 legacy 动画：开门段优先按 “scene marker 含 open” 的节点截取，其次按“位姿变化量最大”的节点；若无明显变化再用“最长持续时间”兜底。
  - 若无法解析动画节点，将回退直接播放 `doorL10/doorR10`。
- AutoStation 开/关门动画与受电弓动画只排队、不带 `reset`（`QueuedAnimations`）。TrainCarts 的 `Attachment#startAnimation` 遇到 `reset`、或不带 `queue` 的动画都会顶掉当前动画并清空排队列表，TC 牌子 `animate queue` 排进去的动画就没了；只排队时等附件上正在播的放完再播，轮到时正放从头、倒放从末尾开始，不需要 `reset`。排队超过 3 秒还没轮到（卡在循环或速度为 0 的动画后面）才带 `reset` 强行播。
- 超级电容车：升弓由站台上的 TC `animate` 牌子负责；停站结束放行发车时，`ptg5`/`ptg6` 还升着（或正排着升弓）就排一个倒放降弓（`SupercapPantograph`）。
- 出库与首站**不做门动画预热**。曾经的预热以 `reset + speed=0` 播放门动画把门摆回起点，但速度为零则动画永远播不完，TrainCarts 只在当前动画播完后才推进附件动画队列，此后显式带 `queue` 且不带 `reset` 的动画（TC 牌子 `animate` 写了 `queue`、命令 `--queue`）会一直卡在它后面；用 chest 生成的车没有这一步，动画从第一次起就能动。
- N/E/S/W/NE/NW/SE/SW 的门侧判定必须由 `doorL/doorR` 附件世界位置决定，不使用列车 facing/travel vector 猜测动画名。附件局部探针仅用于取得更可靠的世界位置，不改变“世界方向投影更大者胜出”的规则。
- 关门提示音：关门时会在门位置播放提示音，仅当附近 12 格内存在玩家时触发。
  - 门位置优先取这节车所开那一组（`doorL/doorL10` 或 `doorR/doorR10`）动画的附件坐标；找不到则回退到车体位置。
  - 提示音会连续播放 3 次，每次间隔 10 tick。

## 自定义关门/开门提示音（Sequencer 标记）
可在模型附件上添加 `sequencer` 名称，用作提示音触发点：

- `doorOpenChime`：开门提示音（仅当定义了自定义声音时触发）
- `doorCloseChime`：关门提示音（优先触发自定义，否则使用默认关门声音）
- `doorChime`：通用提示音（同时作用于开门与关门）

提示音配置建议（附件配置示例，键名可在此处自定义）：
```
sequencer: doorCloseChime
sound: BLOCK_NOTE_BLOCK_BELL
volume: 1.0
pitch: 1.2
```

若未定义 `sound`，关门会回退使用全局默认关门声音；开门无默认音。

默认关门提示音由 `config.yml` 控制：
- `autostation.door-close-sound`
- `autostation.door-close-sound-volume`
- `autostation.door-close-sound-pitch`

## 停站流程
1. 对位并停稳：股道上有合适的停车位置标时车头对准标志，否则车中心对准车站牌子。
   - 两种都由 `StopCurveAction` 开过去，不用 TrainCarts 的居中与距离式 launch（它的平均减速度是 `v²/(2·距离)`，与车型无关：剩余距离短时刹得极急，长时最后几格在站台上慢慢滑）。
   - 量距离：压上站牌时从第一节车厢中心沿轨道走一次，找到停车点所在的轨道（找牌子最多 32 格，找标志最多 1024 格）；车中心对牌子时再加上相邻车厢中心距离之和的一半。弯站台、TCCoasters 上量的都是沿轨道的距离。走到的是牌子所在轨道按列车进入方向的中心，停短判定看的是按牌子朝向的中心，有的轨道两者差半格：再按直线补上这点差（差超过 1 格不补）。第一节车厢已过牌子所在的轨道时按直线投影量过了多少。
   - 之后每 tick 按第一节车厢实际走过的距离扣减余下距离，不再沿轨道走：速度跟着自动运行曲线（车种减速度 × `train.ato-brake-fraction`，与调度控车、编表同一条）在余下距离处允许的值：一段刹到停车点，停车前约 1.6 秒内缓解制动（冲动约 1 m/s³），平稳停住，任何一 tick 都不越过停车点。最后 2 格按 0.02 格的细步长取曲线（天花板 0.25 格一个采样点，缓解段只有半格左右，逐 tick 跟着走会感到减速度一级一级地跳）。进站比曲线略慢（调度压牌前按整格向下取整估停车点）时惰行，等曲线降下来；慢得多（调度按保守估计提前刹了）时才提速回到曲线上。
   - 停车误差：普通停车多走或少走一点（`autostation.stop-scatter-blocks`，默认上限 0.2 格，三角分布，多数在 ±0.1 格内），与实车定位停车相近；填 0 分毫不差。先到联挂站等对方挂上来的停车、停短后的修正不加。
   - 允许走、车却连续 20 tick 不动（被挡住）时结束，交给停稳判定。区块卸载时随列车保存，重新加载后接着走。
   - 量不出车中心到牌子的距离（读不到轨道或车厢位置）时照旧交给 TrainCarts 居中（与 `[train] station` 相同的 center 逻辑）。
   - 停妥后离停车点还差一个“停准”范围以上（进站途中被信号刹了一下）时再量一次、往前补，最多 3 次；量不出就地停妥，不往回开。
   - 停着的车被重新触发本站牌子、车中心已沿前进方向越过牌子（拆开后解下的前一段、挂上后的整列）时就地停住，不按牌子居中往回开：TrainCarts 让停着的车往回开时起步那一拍就把整列调头，车被扣着开不动也会留下反过来的行进方向，驾驶员、车掌判车门左右跟着反（`StopAlignment#centerPastStopPoint`）。车中心还没到牌子时照常往前居中。
2. 停稳后延迟 20 tick 开门（出库后第一站 60 tick，给车门附件与动画预热；编表在这一站多算 2 秒）。开门计划一直规划不出动作（车上没有门附件、判不出开门侧）满一个停站时间（至少 160 tick；门附件晚到的照样能开）时按不开门的停站照常发车（停站从本该开门的那一刻算起，总停站约一个停站时间）（停站任务每秒续发车门锁，不放过这一步会一直扣在站里）。
3. 从开门开始计时，等待 dwell 时间（默认 20s）。
4. 停站门控持有期间只推进 routeIndex 与动态站台选择，不提前写下一跳 TrainCarts destination，避免静止停站时被 TrainCarts 按出口方向反向。
5. 关门动画结束且出站门控放行后，由下一次 signal tick 提交 destination 并发车。
6. dwell 结束后停站任务每秒问一次出站门控。问之前先确认这次停站没被别的流程接手：列车改了名，或改派到了另一条交路（终点待命复用就是这样——改名、换新交路、自行发车），就只收尾（释放本次停站的门控与 dwell 记录、恢复出口偏移、结束 WaitState）后退出，不再替它判"从本站发车"，也不记本站离站。
   - 否则已开走的车会一直以"从本站发车"被判门控，每次判定都刷新它在本站单线区段上的排队位。2026-09-27 实服 NTA：9675 复用为 1673 开走后，对向进站的 4936 因此被挡半小时以上，1673 远在 HHU 仍被"本站发车"扣着。
   - 读不到当前名字或交路不算接手，照旧运行。
